# 当前稳定化与前后端分离计划

本文档记录当前阶段的落地目标，避免还没完成基础治理时过早进入 Redis、消息队列、AI 等扩展功能。

## 阶段目标

当前阶段优先完成：

- 后端 API 稳定化，供 React 前端直接调用。
- 登录、注册、会话状态、简历资料、PDF 导出、公开分享接口闭环。
- 安全收口：密码加密、私有简历访问控制、公开分享数据过滤、配置外置。
- 当前过渡静态页保持可运行，直到 React 前端替换完成。
- 补齐测试，保证后续高并发改造时不破坏核心行为。

## 已完成

- 使用 BCrypt 编码新注册密码，并兼容旧明文密码登录后升级。
- 增加 React 开发环境 CORS 配置，支持带 cookie 请求。
- 增加 `/api/auth/me` 认证状态接口。
- 增加 `/api/profile/share` 分享状态接口。
- 公开分享接口返回过滤后的 DTO，不再直接暴露完整实体。
- 私有预览和私有 PDF 导出校验当前登录用户。
- 修复 `public-share.html` 文件不完整问题。
- 清理登录、注册、编辑页脚本中的乱码提示。
- 动态化模板 2 和模板 3 的教育、技能、经历区域。
- 清理 README 合并冲突。

## 下一步

- 新建 React 前端工程，并用 `/api/**` 接口替换当前静态 HTML 页面。
- 补充 MockMvc 测试：注册、登录、当前用户、资料更新、分享生成/撤销、公开访问、越权访问。
- 加入 H2 测试配置，避免测试依赖本地 MySQL。
- 将 PDF 导出从手写 OpenPDF 排版逐步迁移为基于模板的 HTML to PDF。
- 在 API 稳定后再引入 Redis 缓存、异步导出任务和限流。
